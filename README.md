# Soft_Computing
Fuzzy pattern recognition and weight optimization
There are two projects in this file. 
(1)Adaptive Fuzzy-Neural Pattern Recognition System.This projcet implement a fuzzy patterrn recognition system using Gaussian membership function in python. This project focus on classifying patterns into distinct categories using membership functions. and 
(2) Evolutionary Weight Optimization for a Perceptron Classifier. this project focuses on generalization of population of individuals, where each individual contains a vector of random weights and bias. we use fitness function to described and test how well each set of weights performs on the classification dataset.
